## Overview

**PitchPilot AI Stadium 3D Pro** is an advanced cricket analytics and match prediction dashboard built for portfolio, hackathon, and demo presentation purposes.

The project provides a realistic cricket stadium experience with 3D-style visuals, dynamic team themes, manual score control, live simulation, player impact analysis, AI-style win prediction, pressure reading, and match commentary.

It is a fully working frontend project that can run directly in the browser without requiring any backend database, API key, or external setup.

## Main Features

### Match Setup

- Select tournament type
- Select preset match
- Manually choose Team A and Team B
- Select venue
- Select pitch type
- Select toss winner
- Select toss decision
- Dynamic match theme based on selected teams

### Manual Score Control

- Add current runs
- Add wickets
- Add overs
- Add target score
- Update match situation manually
- Calculate current run rate
- Calculate required run rate
- Analyze match pressure instantly

### Live Match View

- Live scoreboard dashboard
- Ball-by-ball input
- Auto live simulation mode
- Dynamic score updates
- Live match state tracking
- Match momentum calculation

### AI Prediction System

- AI-style win probability
- Team strength comparison
- Toss impact analysis
- Venue impact analysis
- Pitch condition analysis
- Pressure-based match prediction
- Momentum-based tactical reading

### Player Analytics

- Player profile cards
- Batting rating
- Bowling rating
- Fielding rating
- Form rating
- Overall player impact score
- Dynamic Player Impact XI
- 3D hologram-style player cards

### 3D Stadium Experience

- Realistic stadium-style background
- Floodlight effects
- Crowd layer
- Grass depth effect
- 3D live match board
- Dynamic team color theme
- Match background changes based on selected teams and pitch condition

### Demo Modes

The project includes two built-in demo modes:

1. **IPL Death-Over Chase Demo**
   - Simulates a high-pressure IPL chase situation.

2. **World Cup Pressure Match Demo**
   - Simulates an international World Cup-style pressure match.
